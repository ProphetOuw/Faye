Faye

A Roblox reactive UI framework built by MountainDouw. In the docs section i only explain the basics. to view the detailed utility info, go to the Api section.

info

The Thread section in Api will contain most if not all of the utilities and their functions/methods.

Class Name Autocomplete

Thread:Create("...") suggests every creatable Roblox class name. Studio does this out of the box; in VS Code (luau-lsp) press Ctrl+Space inside the quotes, or enable editor.quickSuggestions.strings for [luau] in your settings so it pops up automatically — see the Introduction for the snippet.
